# Python Learning Concepts

This repository is organized into major concept areas, each containing sub-concepts with progressive learning paths. Each sub-concept folder includes:
- `notes.md`: Detailed explanations and teaching content
- `examples.py`: Runnable code examples
- `exercises.py`: Guided exercises (uncomment test code after implementation)
- `solutions.py`: Complete solutions

## Concept Areas

1. **oop** - Object-Oriented Programming (13 sub-concepts)
2. **python_internals** - Python Internals and Execution (14 sub-concepts)
3. **advanced_language_features** - Advanced Language Features (13 sub-concepts)
4. **iterators_data_flow** - Iterators and Data Flow (8 sub-concepts)
5. **threading_synchronization** - Threading and Synchronization (10 sub-concepts)
6. **gil_parallelism** - GIL and Parallelism Model (5 sub-concepts)
7. **multiprocessing** - Multiprocessing (8 sub-concepts)
8. **async_programming** - Async Programming (10 sub-concepts)
9. **testing_advanced** - Testing Advanced (8 sub-concepts)
10. **standard_library_deep_dive** - Standard Library Deep Dive (8 sub-concepts)
11. **static_typing_system** - Static Typing System (6 sub-concepts)

Start with `oop` for foundational OOP knowledge, then explore other areas based on your interests. Each area is numbered for easy progression.
