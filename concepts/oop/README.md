# Object-Oriented Programming (OOP) Concepts in Python

This directory contains progressive lessons on advanced OOP concepts in Python. Each sub-folder focuses on a specific topic, building from basic principles to advanced techniques.

## Learning Path

1. **01_basic_oop** - Classes, instances, methods, and attributes
2. **02_data_model_dunders** - `__str__`, `__repr__`, `__eq__`, `__hash__`, etc.
3. **03_operator_overloading** - Customizing operators with dunder methods
4. **04_abstract_base_classes** - ABC for defining interfaces
5. **05_protocols** - Structural typing with `typing.Protocol`
6. **06_multiple_inheritance_mro** - Multiple inheritance and method resolution order
7. **07_mixins** - Composable functionality through mixins
8. **08_composition_vs_inheritance** - When to use composition over inheritance
9. **09_dataclasses_attrs** - Data-focused classes with dataclasses and attrs
10. **10_immutability** - Creating immutable objects
11. **11_slots** - Memory optimization with `__slots__`
12. **12_metaclasses** - Class creation customization
13. **13_init_subclass** - Hooks for subclassing

Each topic folder contains:
- `notes.md`: Explanations and examples
- `examples.py`: Runnable code examples
- `exercises.py`: Guided exercises with comments
- `solutions.py`: Complete solutions to exercises

Start with `basic_oop` and progress through the list to build a comprehensive understanding of Python's OOP features.
